# Anrika_digital_in

Anrika Digital Innovation — Luxury Haute-Couture Digital Experience & Creative Architecture Studio.

## Overview

A cutting-edge, high-performance web experience built for Anrika Digital Innovation. Crafted with cinematic art direction, interactive canvas sequence animations, bespoke typography, and high-velocity Next.js 15 architecture.

## Tech Stack

- **Framework**: Next.js 15 (App Router, Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion, Canvas 2D Sequence Engine, Lucide Icons
- **Theme Palette**: Luxury Burgundy (`#722F37`), Warm Linen (`#E8DCC6`), Espresso (`#342A29`), Gold Accent (`#C5A880`)

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.
